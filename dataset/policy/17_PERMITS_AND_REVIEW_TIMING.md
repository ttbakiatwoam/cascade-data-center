# Permits and Review Timing

> This file preserves an important distinction from the project research: a state building-plan review timeline is not the same thing as a local zoning or development-approval deadline. This is research, not legal advice.
>
> Last reviewed: 2026-09-10

## Cascade local permit process

Cascade's code requires permits for covered construction and gives the City authority to review submitted plans. The City's building-permit materials require project description, site information, setbacks, and a site drawing.

The project research did **not** identify a general local rule saying a proposed data center is automatically approved if the City does not act within 30, 60, or another fixed number of days. Any actual deadline depends on the specific zoning/permit path, the completeness of the application, hearings, development agreements, state review, and other applicable law.

## Permit exercise and construction-start provisions

Prior review of Cascade's code identified provisions addressing how long an issued permit remains effective and when construction must begin. These provisions govern an already-issued permit; they should not be confused with a deadline requiring the City to approve a pending application.

Because Cascade's online zoning chapter preserves the underlying 1992 zoning ordinance and amendments rather than reproducing the full zoning text, the current saved zoning documents should be checked before relying on any precise local timing statement.

## Iowa state plan-review rule: 60 days

Iowa Administrative Code rule 481—300.4 contains a 60-calendar-day provision for certain **state Building Code Bureau plan reviews for which a review fee is assessed**.

The rule provides that, when a complete plan subject to the rule has not been approved or rejected within 60 calendar days after receipt, the submitter may be eligible for a refund of the plan-review fee.

The remedy described by the rule is a **fee refund**, not automatic plan approval. It also applies to the state Building Code Bureau review process described by the rule, not automatically to municipal zoning, rezoning, site-plan, special-use, development-agreement, utility, or other local approvals.

This distinction is important because citing “Iowa has a 60-day approval rule” without identifying the specific state plan-review rule materially overstates what the rule does.

## Practical Cascade sequence

A large industrial computing project may require several distinct tracks, potentially including:

1. land-use/zoning determination;
2. rezoning or other discretionary land-use approval if required;
3. site/civil review;
4. development or utility agreements;
5. state building-code plan review where applicable;
6. fire, electrical, plumbing, mechanical, accessibility, or other code review;
7. state/federal environmental or utility permits where applicable;
8. construction permit issuance;
9. inspections and certificate-of-occupancy requirements.

A deadline attached to one track should not be treated as a deadline for every other track.

## Dataset conclusion

For the Cascade project, any assertion that the City “must approve” a complete data-center proposal in a fixed number of days should identify the exact statute, ordinance, rule, approval type, and remedy. The 60-day Iowa state building-plan-review provision recovered in this research does not itself create automatic local zoning approval.
